# RNA-seq project
- this is a RNA sequencing project for first semester bioinformatics students
- Overall goal of the project is to evaluate differences in gene expression of mice infected with parasite toxoplasma gondii.
- RNA probes originate from lung tissue and further information about the sequencing results can be found in the data_README.md file
- the detailed procedure of the project can be found in notes/step_by_step.txt
- the final report: RNA_seq_course.pdf
